# Icon atlas

The bundled atlas contains sixteen icons on a transparent 4 × 4 grid. It is loaded once, cropped into frozen WPF images and cached. It is not extracted from Windows Shell or an installed application.

Rows: folder / drive / document / picture; music / video / archive / code; home / download / profile / bookmark; search / settings / trash / copy.

The Glass name describes the decorative icon material. It does not enable transparency behind the application window.
