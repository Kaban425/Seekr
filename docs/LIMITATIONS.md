# Ограничения текущего выпуска

- Интерфейс предназначен для Windows x64. На macOS доступна разработка и проверка переносимой части.
- Поиск работает по имени, расширению, размеру и датам. Поиск текста внутри файлов в интерфейсе отключён.
- Начальный индекс готовится в фоне. Недоступные файлы не становятся доступными благодаря службе; просмотр папок работает без неё.
- Размер папки — сумма доступного содержимого. Знак ≥ означает неполный подсчёт. Это не гарантированно освобождаемое место; ссылки, облачные файлы и права доступа влияют на результат.
- Ctrl+Z отменяет поддерживаемое переименование и перемещение без замены на одном диске, пока запись доступна в истории. Для безопасного снимка содержимого действует суммарный предел 64 МБ и не более 100 000 записей. Междисковое, частичное перемещение, замена и объединение возвращаются вручную. Изменившееся содержимое или занятое исходное имя препятствуют автоматической отмене. Удаление, очистка и завершение процессов не отменяются.
- Отмена операции останавливает дальнейшую обработку; уже выполненные действия не откатываются автоматически. Проверяйте состояние каждого файла в очереди.
- Поиск дубликатов и очистка предлагают кандидатов. До удаления нужен ручной выбор и подтверждение. Сканирование ограничено 100 000 записей; ссылки не обходятся.
- Проверка блокировок папки ограничена 5000 путями. Отсутствие найденного процесса не означает наличие прав на удаление.
- PDF-предпросмотр зависит от WebView2 Runtime. Недоступный формат можно открыть во внешней программе.
- Сессия сохраняется периодически и при нормальном выходе. После сбоя последние изменения могут отсутствовать.
- Прозрачность рабочего стола не используется. Темы, обои и декоративные значки доступны.
- Выпуск не подписан сертификатом издателя. SmartScreen может показывать предупреждение.

При проблеме приложите к [обращению](https://github.com/Kaban425/Seekr-Feedback/issues/new/choose) версию, шаги воспроизведения и ожидаемый результат. Не публикуйте личные файлы и необработанные отчёты.
