# Сборка и устройство проекта

## Требования

Полный интерфейс WPF работает и тестируется на Windows. Нужны Git, .NET 10 SDK и PowerShell 7.2+ для упаковки. Visual Studio необязательна. Для готовой программы SDK не нужен.

```powershell
dotnet restore Seekr.slnx
dotnet build Seekr.slnx -c Release
dotnet test Seekr.slnx -c Release
dotnet run --project src/Seekr.App -c Release
```

На macOS можно менять исходники и проверять переносимую часть командой `bash scripts/check-mac.sh`. Этот сценарий не проверяет WPF и Windows-зависимые операции.

## Проекты

| Каталог | Ответственность |
|---|---|
| src/Seekr.App | WPF-интерфейс, операции, настройки, вкладки и сессии. |
| src/Seekr.Core | Модели индекса, парсер запросов и поиск. |
| src/Seekr.Indexer | Получение файловых данных и протокол индексации Windows. |
| src/Seekr.Elevated | Необязательная служба чтения индекса NTFS. |
| src/Seekr.Setup | Установщик с встроенным MSI. |
| tests | Модульные, файловые, оконные и установочные проверки. |
| tools | Стенды переносимых сценариев, производительности и установки. |
| distribution/feedback | Страница скачивания и шаблоны обращений. |

## Комплект выпуска

```powershell
pwsh -File scripts/build-release.ps1 -Version 1.0.7 -BuildNumber 8
```

Сценарий запускает тесты, собирает автономные приложение и службу, MSI, внешний EXE, ZIP и манифест SHA-256. WiX 4 загружается в локальный каталог инструментов; результат находится в artifacts/release/1.0.7. Сборочные каталоги не входят в Git.

Для следующего опубликованного комплекта повышайте patch-номер. Установщик использует стабильный ProductCode для одной версии. Текущий выпуск не подписан; параметры подписи доступны, но не включены по умолчанию.

Установочные проверки выполняйте в отдельной виртуальной Windows. scripts/test-installer.ps1 и tools/Seekr.SetupCheck могут устанавливать и удалять тестовый продукт; не запускайте их поверх рабочей установки.

CI на Windows собирает решение и запускает тесты. Успешная автоматическая проверка не гарантирует отсутствие ошибок на каждом устройстве. Перед выпуском проверяйте обновление, файловые операции и основные сценарии интерфейса в виртуальной машине.
