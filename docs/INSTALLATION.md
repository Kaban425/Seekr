# Установка и обновление

Готовые файлы: [Seekr Releases](https://github.com/Kaban425/Seekr-Feedback/releases/tag/v1.0.7). Версия 1.0.7, сборка 8, Windows x64.

1. Закройте запущенный Seekr и скачайте Setup.exe либо MSI. Одновременно устанавливать оба не нужно.
2. Выберите папку и создание ярлыка. Установщик включает .NET и работает без интернета.
3. После запуска выберите диск слева. Просмотр папок доступен до завершения индексации.
4. При необходимости установите службу из окна состояния поиска. Административные права нужны для установки и обновления службы.

ZIP распаковывается целиком; запускайте Seekr.App.exe. Автоматические архивы Source code на GitHub содержат исходники, а не готовую программу.

Подпись издателя не используется. Windows может предупредить о неизвестном приложении. Не отключайте защиту ради установки. Контрольные суммы находятся в release-manifest.json; SHA-256 можно проверить командой Get-FileHash.

Настройки, сессия и отчёты находятся в `%LocalAppData%\Seekr`. Сохранённые поиски и оформление сохраняются при обычном обновлении. Профиль DarkGlass из старых сборок заменяется матовым Graphite; прозрачности за окном нет.

Удаление: Параметры Windows → Приложения → Seekr → Удалить. Отдельно установленную службу можно удалить через окно состояния поиска. Личные файлы не удаляются; настройки и отчёты остаются в профиле пользователя.
