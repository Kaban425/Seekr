# Seekr 1.0.6 — сборка 7

Файловый менеджер для Windows x64: вкладки, две панели, поиск с фильтрами, размеры папок, сохранённые поиски, файловые операции и персональные оформления.

Подготовлены открытые исходники и единая документация, обновлён комплект распространения. Настройки восстанавливаются повторным нажатием кнопки и остаются над главным окном. Прозрачности рабочего стола нет; матовые темы, обои и значки сохранены.

Скачивание: https://github.com/Kaban425/Seekr-Feedback/releases/tag/v1.0.6

Исходники: https://github.com/Kaban425/Seekr

Ошибки: https://github.com/Kaban425/Seekr-Feedback/issues/new/choose

Выберите Setup.exe, MSI или полный ZIP. Setup включает MSI и .NET; интернет для установки не нужен. Перед обновлением закройте программу. Не устанавливайте EXE и MSI как отдельные продукты.

Выпуск не подписан сертификатом издателя. Windows может показать предупреждение SmartScreen. Не отключайте защиту; скачивайте комплект по указанному адресу и проверяйте SHA-256 из release-manifest.json.

Ctrl+Z поддерживает переименование и перемещение без замены на одном диске, при доступном снимке содержимого до 64 МБ. Удаление и замену он не отменяет. Поиск содержимого отключён в интерфейсе. Для PDF нужен WebView2 Runtime. Размеры папок могут быть неполными и не равны гарантированно освобождаемому месту.

Настройки и отчёты: %LocalAppData%\Seekr. Диагностика отправляется по выбору пользователя; перед публикацией проверьте вложения. Для проверки операций используйте отдельную тестовую папку.
